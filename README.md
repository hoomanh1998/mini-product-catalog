# Mini Product Catalog Application

A mini product catalog application built with **React**, **Next.js 15**, **Tailwind CSS**, and **Supabase**. This project showcases front-end development, performance optimization, and optional AI integration — designed to demonstrate the skillset for a Senior Front-End Developer role at ClicTiv.

## 🧰 Tech Stack

- **Frontend:** React, Next.js v15
- **Styling:** Tailwind CSS v4
- **State Management:** Zustand
- **Backend:** Supabase (PostgreSQL)
- **Testing:** Jest
- **Deployment:** Vercel
- **Package Manager:** pnpm

## 📊 Supabase Table and Schema

### Table: `Products`

| Column Name  | Type          | Description                                 |
|--------------|---------------|---------------------------------------------|
| `id`         | `bigint`      | Primary key, auto-incremented               |
| `name`       | `text`        | Product name                                |
| `description`| `text`        | Product description                         |
| `image_url`  | `text`        | Public URL of the product image             |
| `price`      | `integer`     | Product price in USD                        |
| `created_at` | `timestamptz` | Timestamp when the product was added        |

### SQL Definition

```sql
create table products (
  id bigint generated by default as identity primary key,
  name text not null,
  description text,
  image_url text,
  price integer
  created_at timestamptz default now(),
);
```

## 📡 API Route Descriptions
Below are the REST API routes for `Products` table.

### `GET /api/products`

- **Description:** Retrieve a list of all products.
- **Response:**
  ```json
  [
    {
      "id": 1,
      "name": "iPhone 16",
      "description": "The iPhone 16 features a sleek design...",
      "image_url": "https://.../iphone16.jpg",
      "price": 1099
      "created_at": "2025-04-29T14:46:12.965Z",
    }
  ]
  ```

### `GET /api/products/:id`

- **Description:** Retrieve a single product by its ID.
- **Route Parameter:** `id` (number).
- **Response:**
  ```json
    {
      "id": 1,
      "name": "iPhone 16",
      "description": "The iPhone 16 features a sleek design...",
      "image_url": "https://.../iphone16.jpg",
      "price": 1099
      "created_at": "2025-04-29T14:46:12.965Z",
    }
  ```

### `POST /api/products`

- **Description:** Create a new product.
- **Request Body:**
  ```json
    {
      "id": 1,
      "name": "iPhone 16",
      "description": "The iPhone 16 features a sleek design...",
      "image_url": "https://.../iphone16.jpg",
      "price": 1099
      "created_at": "2025-04-29T14:46:12.965Z",
    }
  ```
- **Response:** Created product object including `id` and `created_at`.

### `PUT /api/products/:id`

- **Description:** Update an existing product with ID.
- **Route Parameter:** `id` (number).
- **Request Body:**
  ```json
    {
      "id": 1,
      "name": "iPhone 16",
      "description": "The iPhone 16 features a sleek design...",
      "image_url": "https://.../iphone16.jpg",
      "price": 1099
      "created_at": "2025-04-29T14:46:12.965Z",
    }
  ```
- **Response:** Updated product object.

## 🧪 Testing Strategy

This project uses **Jest** for unit testing.

### Running Tests

```bash
pnpm test
```

### Configuration
- Unit tests are located alongside components as `.test.tsx` files.
- Jest is configured in `jest.config.ts` with jsdom environment.

## ⚙️ CI/CD Pipeline
This project uses GitHub Actions for CI:

### `.github/workflows/ci.yml`
```yml
name: CI Workflow

on:
  push:
    branches:
      - frontend-challenge
  pull_request:
    branches:
      - frontend-challenge

jobs:
  linting:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Set up Node.js
        uses: actions/setup-node@v3
        with:
          node-version: "18"

      - name: Install pnpm
        run: npm install -g pnpm

      - name: Install dependencies
        run: pnpm install

      - name: Run ESLint
        run: npx eslint . --ext .js,.jsx,.ts,.tsx

  type-checking:
    runs-on: ubuntu-latest
    needs: linting

    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Set up Node.js
        uses: actions/setup-node@v3
        with:
          node-version: "18"

      - name: Install pnpm
        run: npm install -g pnpm

      - name: Install dependencies
        run: pnpm install

      - name: Run TypeScript check
        run: npx tsc --noEmit

  testing:
    runs-on: ubuntu-latest
    needs: type-checking

    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Set up Node.js
        uses: actions/setup-node@v3
        with:
          node-version: "18"

      - name: Install pnpm
        run: npm install -g pnpm

      - name: Install dependencies
        run: pnpm install

      - name: Run Jest tests
        run: pnpm test
```
